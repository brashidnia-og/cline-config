# Arena-game-v1 example

The project stores game decisions in `docs/GDD.md` and `docs/DECISIONS.md`. `docs/research/FU_MAP_CATALOG_AUDIT.md` and `docs/FU_THUMBNAIL_MAPS.md` map reference images to the game's own playable arena geometry; tests check spawn, floor, and camera constraints. `docs/REFERENCE.md`, `docs/BOT_AI.md`, and `docs/COMBAT_FEEL.md` record bot and combat rules, while `tools/bot_eval.py` provides repeatable bot scenarios.

The transferable method is source evidence → explicit project decision → executable scenario → visual/playtest review. A reference screenshot can suggest shape or spacing, but does not establish unseen collision, timing, or AI policy. Keep those interpretations labeled.
